# Set up your brand

The brand is the highest-leverage thing you will configure: every piece every
agent makes inherits it. One good hour here saves you from style corrections
forever.

## Path A — you already have a brand

If you have a live website, start by **importing** it:

1. In your agent's chat, ask it to import your brand from your site URL.
2. Syvon extracts the palette, the fonts (downloading the real font files),
   and the logo, and assembles a brand DNA.
3. Review what it found — this part is worth ten honest minutes:
   - **Colors**: are the roles right? (Which one is the primary, which is
     the accent, which is just background.)
   - **Logo variants**: you want at least the full lockup **and** a
     light/reversed mark for dark backgrounds.
   - **Voice**: the importer can't read your voice from CSS — describe it in
     a sentence ("confident, dry, never breathless") and ask the agent to set
     it.

## Path B — starting fresh

No brand yet, or exploring a new one? Ask for a **proposal** with a plain
description:

> "A bold, dark, editorial fintech brand. Precise, premium, nothing playful."

Syvon drafts a complete DNA — palette, a font pairing, voice. Accept it,
adjust it, or ask for another take. Drafts are free; commit when one feels
right.

## Adding real assets

Whatever path you took, round it out:

- **Fonts** — import the actual families (weights included) so renders use
  the real faces, not approximations.
- **Logo** — bring in each variant and label it (symbol / wordmark / lockup,
  color / reversed).
- **Imagery** — drop in a few photos that feel right; generation steers
  toward them.

## Test the brand before trusting it

Ask the agent for two throwaway pieces — one motion, one still — with
different briefs. You're checking that the *system* (roles, scale, logo
treatment) works across shapes, not that any single piece is pretty. Fix the
DNA where both pieces miss the same way; fix the brief where they don't.
