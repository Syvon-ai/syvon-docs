# Glossary

| Term | One line |
|---|---|
| **Agent** | A configured content-maker — one job, one brand, its own chat and project |
| **Brand** | The DNA — colors, type, logo, imagery, voice — that styles all generation |
| **Brief** | What you write in a chat to get a piece; describes the outcome, not the layout |
| **Caption** | The text on a published card, per piece |
| **Channels** | Where a published piece goes (site, social shapes) |
| **Chat** | The conversation with an agent; the main working surface |
| **Composition** | The live, previewable piece a generation produces before rendering |
| **Credits** | The unit of compute spend; generation, rendering, voice spend them |
| **Feed** | The published view of a project's output — what the site and channels read |
| **Flow** | An agent's recipe: medium, format, voice, captions, music, pacing defaults |
| **Generation** | One act of making: brief in, composition out |
| **Medium** | Motion (video) or still — a flow's core setting |
| **Project** | An agent's working set: drafts, renders, published files |
| **Publish** | The act that puts a rendered piece on the feed (free, reversible) |
| **Render** | Turning a composition into a finished file; the main credit spend |
| **Sidecar** | The small record next to a rendered file whose channels decide visibility |
| **Studio** | The desktop app where you chat, edit, render, and publish |
| **Variant** | The same piece re-composed for another format ("a 9:16 of this") |
| **Voice** | The brand's copy personality, and the narration option on flows |
| **Wrapper site** | The public website a workspace gets, assembled from its content |
| **Workspace** | The top container — one business, everything inside it |
